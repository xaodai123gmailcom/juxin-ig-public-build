# 聚鑫国际 v3.0.4 验收清单

此清单为验收要求；勾选须来自同一提交、同一最终安装器的实际证据。

- 公开 schema 2 源码身份与真实 GitHub Actions 检出的 HEAD、仓库和清单完全一致
- Windows x64 全量构建通过；构建电脑及目标电脑已有 Google Chrome
- 版本 3.0.4、准确 NSIS 文件名、SHA-256 sidecar 和 LATEST_SUCCESS.txt 相互一致
- 源码、后端、renderer、Electron、真实浏览器、冻结 Core 和模型运行时门禁全部执行
- 最终安装器安装后，实际桌面和它的冻结 Core 通过认证 API 恢复验证
- 发帖和 Pexels 页面、接口、执行器与报表入口移除；旧内容经验证的可恢复归档保存，活动或不确定占用不抢占
- 隐藏暂停采集仅精确定位当前所有者的目标任务；停止后仍须权威关闭证明才能释放占用
- 采集、养号和账号管理继续使用原窗口独占；暂停、未完成清理和未知状态不得被其他任务抢占
- 采集遇到可恢复页面错误时保留检查点；新页有效进展持久化后才释放旧页；平台限制不绕过
- 七个采集计数、完整历史、精确报表及完整 CSV 保持一致；未知数字不冒充零
- 存储清理不删除用户数据库、账号登录资料、Cookie 或业务历史
- 云端默认关闭；仅在明确配置并启用自己的项目后可登录和上传，停用保留本机记录
- 可选翻译无脚本时清楚显示不可用；本地导入校验和隔离适配器测试通过
- 原生截图和报告来自本次实际执行；静态、合成、第三方服务和实机证明分别标注

真实网站、真实账号和用户数据库不属于离线合成验收。没有运行的阶段不得标记为通过。
